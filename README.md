# 건국이엔아이 조직도 시스템

공사사업부 인원 조직도 웹앱 — React(Vite) + Vercel + Google Apps Script/Sheets (MRS와 동일 구성)

## 구성
| 구분 | 위치 | 내용 |
|---|---|---|
| DB | 구글시트 「조직도DB_건국이엔아이」 | 인원 / PJT / 코드 / 이동이력 / 계정 / 설정 탭 |
| API | `apps-script/Code.gs` | 로그인(토큰), 조회, 등록·수정, PJT 이동, 퇴사·휴직, 사진 업로드, 이력 자동 기록 |
| 화면 | `src/` | 로그인 · 조직도 · PJT별 조직도 · 명단·현황 · 관리(admin) |

## 1. Apps Script 배포 (최초 1회)
1. 구글시트 열기 → **확장 프로그램 > Apps Script**
2. 기본 `Code.gs` 내용을 지우고 `apps-script/Code.gs` 전체 붙여넣기 → 저장
3. 시트 새로고침 → 상단 메뉴 **조직도 > 초기 설정** 실행 (권한 승인) → 사진 폴더 자동 생성
4. **조직도 > 비밀번호 설정** → 아이디 `admin`, 비밀번호 입력
5. Apps Script 화면 **배포 > 새 배포 > 유형: 웹 앱**
   - 실행 사용자: **나** / 액세스 권한: **모든 사용자**
   - 배포 후 나오는 URL(`https://script.google.com/macros/s/…/exec`) 복사
> 코드 수정 시: 배포 > 배포 관리 > 편집 > 버전 「새 버전」으로 재배포 (URL 유지)

## 2. Vercel 배포
1. 이 폴더를 GitHub 저장소로 올림 → Vercel에서 Import (Framework: Vite 자동 인식)
2. Settings > Environment Variables: `VITE_API_URL` = 1-5의 웹 앱 URL
3. Deploy → 발급된 주소로 접속
> `VITE_API_URL` 없이 실행하면 **데모 모드**(서버 없이 화면 확인, admin/admin1234 · viewer/viewer1234)

## 3. 운영
- **계정 추가**: 계정 탭에 행 추가(아이디·이름·권한 admin/viewer·사용여부 Y) → 메뉴 [비밀번호 설정]
- **비밀번호**: 시트에는 해시값만 저장. 사용자는 화면 우측 상단 「비밀번호」에서 직접 변경
- **PJT 추가**: PJT 탭에 행 추가(표시순서, 사용여부 Y) → 탭·필터·현황표 자동 반영
- **직급·직무·역할 추가**: 코드 탭 해당 열에 추가 (순서 = 화면 표시 순서)
- **팀장 지정**: 인원 탭 「팀장」 Y 또는 관리 화면 체크
- **PJT별 조직도 상단**: 인원 탭 「역할」 (책임기술자 / 선임 안전관리자 / 현장 안전 등)
- **사진**: 관리 화면에서 업로드(3:4 자동 맞춤, 300×400) → 드라이브 「조직도_사진」 폴더에 비공개 저장, 로그인 사용자만 조회
- **퇴사**: 삭제 대신 재직상태 「퇴사」 → 조직도 제외, 이력 보존

## 로컬 실행
```
npm install
npm run dev        # 데모 모드
```
